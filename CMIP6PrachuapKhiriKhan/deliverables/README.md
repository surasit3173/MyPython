# Prachuap Khiri Khan ENSO & QDM Manuscript Deliverables Package

This directory contains the final, publication-ready deliverables package for the research article:

**"Seasonal and Extreme Rainfall Variability in Prachuap Khiri Khan and Its Relationship with ENSO: Evaluating Signal Preservation in Quantile Delta Mapping"**

## Package Contents

1. `Manuscript_Prachuap_ENSO_QDM.docx` — Complete English Manuscript (Word DOCX)
2. `Manuscript_Prachuap_ENSO_QDM.pdf` — Publication-ready Manuscript PDF
3. `Tables_Prachuap_ENSO_QDM.docx` — Final Tables 1–4 in Word DOCX
4. `figures/` — Individual Figure Files 1–5 + Graphical Abstract (600 DPI PNG + Vector PDF)
5. `Supplementary_Material.docx` — Supplementary Information Document
6. `Cover_Letter.docx` — Formal Cover Letter to Editor-in-Chief
7. `Data_Code_Availability.md` — Data & Code Availability Statement
8. `audits/` — Numerical Audit, Table-Figure Consistency Audit, and Submission Checklist
