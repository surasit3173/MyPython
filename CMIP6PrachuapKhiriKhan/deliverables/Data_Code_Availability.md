# Data and Code Availability Statement

## Observational Data
Daily precipitation records (1981–2014) for 12 meteorological stations in Prachuap Khiri Khan were provided by the Thai Meteorological Department (TMD) and Royal Irrigation Department (RID).

## CMIP6 Model Simulations
CMIP6 historical daily precipitation outputs (ACCESS-ESM1-5, CESM2, CanESM5, EC-Earth3, MIROC6) are publicly available via the Earth System Grid Federation (ESGF) portal.

## ENSO Indices
NOAA CPC Oceanic Niño Index (ONI) ERSSTv5/v6 data are available from the NOAA Physical Sciences Laboratory.

## Code
Python pipeline scripts for data quality control, QDM bias correction, bootstrap/permutation testing, and figure generation are archived in the project repository under `CMIP6PrachuapKhiriKhan/scripts/`.
