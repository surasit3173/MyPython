1. METHODOLOGICAL SPECIFICATIONS
--------------------------------------------------------------------------------
Interpolation Algorithm   : 2D Inverse Distance Weighting (Shepard's Method)
Target Hydrological Field : 34-Year Mean Annual Precipitation (mm/year, 1981-2014)
Input Sample Size         : N = 12 Ground Meteorological Stations (Authentic Records)
Distance Power (p)        : 2.0 (Inverse distance squared weighting)
Search Neighborhood       : Global (k = 12 stations, all active gauges utilized)
Coordinate System         : WGS84 Geographic (EPSG:4326)
Spatial Extent (WGS84)    : Longitude 99.14°E - 100.02°E, Latitude 10.95°N - 12.65°N
Grid Cell Resolution      : 0.005° x 0.005° (approximately 500 m x 500 m)
Grid Matrix Dimensions    : 345 rows x 184 columns (63480 nodes)
Active Provincial Cells   : 23011 raster cells within provincial polygon
Interpolated Surface Range: Min = 944.15 mm/yr, Max = 1373.81 mm/yr
Spatial Boundary Masking  : Strict polygon clipping via Natural Earth 10m Provincial Polygon
